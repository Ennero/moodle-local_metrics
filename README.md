## 📌 Descripción General

Este repositorio contiene la implementación y entrega de **📈 Moodle LMS Custom Telemetry & Analytics Plugin (PHP)**, desarrollado en el curso de **Desarrollo / Plataformas Educativas** en la Universidad de San Carlos de Guatemala.

- **Objetivo:** Plugin para Moodle LMS que recopila telemetría de estudiantes, métricas de rendimiento y reportes de actividad académica.
- **Stack Principal:** `PHP`.
- **Área:** Ciencias de la Computación, Algoritmos y Desarrollo de Software.
